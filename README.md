# Aditi Anupam, portfolio

My portfolio as an animator and motion designer. Cloudflare Pages publishes this folder exactly as it is, so any change saved here goes live within a minute or two.

- `index.html` is the page itself.
- `app/` holds the styles, scripts and words. `app/copy.js` has most of the text.
- `app/news.js` holds the headlines along the top of the home page. A scheduled task updates it twice a day.
- `media/` holds the films, drawings, photos and sounds.
- `fonts/` holds the fonts.

Cloudflare settings: no build command, output folder `/`.
